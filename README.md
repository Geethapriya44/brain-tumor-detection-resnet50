Brain Tumor Detection Using Deep Learning

📌 Project Overview

This project focuses on detecting brain tumors from **MRI images using Deep Learning**. An end-to-end image classification pipeline was developed, including image organization, preprocessing, augmentation, feature extraction, model training, and prediction.

The project uses the **ResNet50 architecture** with transfer learning to extract meaningful features from brain MRI images and classify them into tumor and non-tumor categories.

🎯 Objectives

* Detect brain tumors from MRI images using deep learning.
* Perform image data preprocessing and normalization.
* Apply image augmentation to improve model generalization.
* Use **ResNet50** for feature extraction.
* Train a classification model using extracted features.
* Predict the class of a new, unseen brain MRI image.

Image Data Preprocessing

The MRI images were prepared for deep learning through preprocessing steps such as:

* Image resizing
* Image format preparation
* Pixel normalization
* Dataset organization
* Train, validation, and test data splitting

Image Augmentation

Image augmentation was applied to the training data to introduce variations in MRI images and help the model generalize better to unseen images.

ResNet50 Model

ResNet50  was used as the main deep learning architecture.

The pretrained ResNet50 network was used for **feature extraction**, allowing the model to learn useful high-level visual representations from MRI images. These extracted features were then used for classification.

📊 Results

The trained model achieved:

Test Accuracy: 82%*

The model was also tested with new brain MRI images to generate predictions.

The reported accuracy represents the performance obtained on the test dataset used in this project.
